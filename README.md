# MAX Web Client

Неофициальный клиент для **Windows 10 x64 и Windows 11 x64**. Electron открывает официальный сайт https://web.max.ru/ в отдельном окне. Авторизация, QR-код и переписка предоставляются самим MAX; клиент не реализует собственный протокол и не перехватывает учётные данные.

## Сборка на Linux VPS в Docker

Нужен Linux VPS x86_64 с установленными Docker Engine и Docker Compose plugin. Windows, графическая среда и установка Node.js на VPS не требуются. На ARM VPS потребуется эмуляция amd64; предпочтительнее x86_64.

Загрузите исходники в каталог на VPS, перейдите в него и выполните:

```sh
docker compose run --build --rm build-windows
```

Контейнер использует Wine и electron-builder для сборки Windows-приложения. Интернет нужен для загрузки образа, npm-пакетов, Electron и инструментов упаковки. Docker запускается только на VPS, приложение запускается на Windows без Docker.

Готовые файлы находятся **на VPS в `dist/`**:

- `MAX-Web-Client-0.1.0-x64-nsis.exe` — установщик с выбором каталога.
- `MAX-Web-Client-0.1.0-x64-portable.exe` — portable-версия.

Скачайте их через SFTP или выполните на своём компьютере (подставьте пользователя, адрес VPS и абсолютный путь):

```powershell
scp user@VPS:/absolute/path/max-client/dist/*.exe .
```

Если Docker создал файлы от root, при необходимости смените владельца:

```sh
sudo chown -R "$(id -u):$(id -g)" dist
```

EXE не подписаны цифровым сертификатом. Windows может показать предупреждение SmartScreen. Для распространения с доверенной подписью потребуется отдельный сертификат подписи кода.

## Вход и использование

1. Запустите установленный клиент или portable EXE на Windows.
2. На странице MAX выберите вход по QR-коду, если он предлагается веб-версией, и подтвердите вход в мобильном MAX.
3. Сессия сохраняется локально в профиле приложения. Portable означает запуск без установки, а не хранение сессии рядом с EXE.

Кнопка закрытия сворачивает приложение в трей. Для завершения используйте «MAX → Выход» или меню трея. «MAX → Сбросить вход» удаляет локальную сессию после подтверждения. Ctrl+R перезагружает страницу. Внешние HTTP/HTTPS-ссылки открываются в системном браузере; другие протоколы заблокированы.

Данные профиля находятся в `%APPDATA%\max-web-client` (профиль Electron). Не передавайте этот каталог другим людям: он содержит сессию входа. Удаление локальной сессии не заменяет отзыв устройства через настройки MAX.

Доступные функции, уведомления, звонки и способ авторизации зависят от веб-версии MAX и разрешений Windows. Собственный автообновлятор не предусмотрен: новый EXE нужно собрать и скачать повторно.

## Разработка и проверки

```sh
npm ci
npm start
npm run check
```

`npm start` требует графической среды и не нужен на VPS для сборки. `npm run check` выполняет проверку синтаксиса и тесты ограничений ссылок без установки зависимостей и без сборки EXE.

Сборка и запуск на Windows ещё не проверены. Для приёмки после сборки проверьте установщик и portable EXE на Windows 10: вход по QR, повторный запуск с сохранением сессии, отправку сообщения, внешние ссылки, сворачивание в трей и сброс входа. Звонки и уведомления проверяйте отдельно, если они нужны.
